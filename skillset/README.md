# Jonatas Workflow skillset

Jonatas's skillset: the execution core that came with Nori, Matt Pocock's definition skills, and the Maestri skills, with the global `AGENTS.md` that governs all of them. `bin/install` links it into `~/.claude`: `AGENTS.md` as `CLAUDE.md`, `skills/` into `~/.claude/skills/` and `subagents/` into `~/.claude/agents/`.

The skills say how an agent works a slice; they do not say what runs. That is the round: a manifest of one cluster of connected tickets the Definer closed with Jonatas, dispatched by the Orchestrator, implemented by executors in parallel worktrees, merged by Jonatas himself.

Read `../README.md` for the repository, and `../docs/workflow.md` for how a round runs.
